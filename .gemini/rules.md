# Project Rules & Design Guidelines

## Icon & UI Standards
1. **NEVER USE EMOJIS ANYWHERE IN THE SYSTEM**:
   - Do not use emojis in UI labels, buttons, navigation tabs, status badges, metrics, forms, or data tables.
   - Do not use emojis in country codes or regional settings.
   - Do not use emojis in system notifications or admin badges.

2. **ALWAYS USE MINIMALIST SHOPIFY / LUCIDE ICONS**:
   - Always import and render crisp, professional SVG icons from lucide-react (e.g. Flame, Snowflake, Sun, Megaphone, RotateCcw, BarChart2, CheckCircle, CheckCheck, Check, Eye, TrendingUp, Coins, Calendar, Zap, AlertCircle, Cake, HeartPulse, Sparkles, FlaskConical).
   - Style icons with standard Tailwind classes: e.g. w-3.5 h-3.5 text-accent, w-4 h-4 text-text-muted, w-3 h-3 text-sky-400.
   - Maintain a clean, minimalist Shopify Polaris aesthetic across all screens.
